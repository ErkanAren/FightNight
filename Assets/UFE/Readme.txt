Universal Fighting Engine 2 (v2.7.3)

Thank you for choosing UFE Standard for Unity.

Read Installation.pdf for the illustrated setup guide.
Start with a clean Built-In Render Pipeline project.
This package excludes top-level ProjectSettings files. Let UFE Project Setup
install the required settings, then restart Unity when prompted.
Version 2.7.3 adds basic animation previews and persistent editor selections,
plus gameplay and Unity compatibility fixes.
Compiled runtime and editor libraries are included; full engine C# source
is available separately in the Source edition.

If you are having issues with the installation please consult this link:
https://www.ufe3d.com/ufe2/docs/#/installation

Important Unity 6 note:
UFE requires Unity's UI package (com.unity.ugui). If you are importing UFE
into a clean Unity 6 project, make sure the package is installed under
Window > Package Management > Package Manager before opening the demo scenes.


Open any of the scenes below to play the demo:
- UFE\Demos\_2DFighter\Demo 2D Fighter.unity
- UFE\Demos\_2DFighter\Shell_Mode\Demo 2D Fighter (Shell).unity
- UFE\Demos\_3DArena\Demo 3D Arena.unity
- UFE\Demos\_3DFighter\Demo 3D Fighter (Type 1).unity
- UFE\Demos\_3DFighter\Demo 3D Fighter (Type 2).unity

The global configuration file is under the same folder (Config_PROJECTNAME.asset).
